Introduction 
1.1 Purpose 
 
 
The purpose of this document is to define and provide details for accessing API for JIOBP 
system information (information about oil and natural gas stations based on State 
Code or geographical location (longitude, latitude, and radius) value from ULIP system 
 
This document details the following points: 
 
1. Data Integration between JIOBP and ULIP web service: Identification of 
operational points where data integration between JIOBP and ULIP web service will 
be needed. 
 
2. Technical Approach for performing Data Integration 
 
The Overall Description 
 
Users will need to share their State Code, state name or geographical location (longitude, 
latitude, and radius) to access the list of public petroleum and natural gas stations through 
the rest API. 
 
Here are some points to keep in mind when accessing JIOBP API data information: 
 
• The API will only share data that is based on the user's provided information. 
• ULIP will expose an API for getting data from the JIO BP. 
• The JIOBP/01 API will take State Code, state name or geographical location 
(longitude, latitude, and radius) to give information about petroleum and natural gas 
stations to the user. 
 
1.2 Data Integration between JIOBP System and ULIP application 
The ULIP system will receive information from the user and provide data in return. 
 
1.3 JIOBP/01 
This API is designed to retrieve information about petroleum and natural gas stations. It 
can be used by providing either the take State Code, state  name or the geographical

1.3.1 Technical Approach 
1. All the data will be shared through REST web services. 
2. The user will share the input for which information is required. 
3. JIOBP API will share details of JIOBP fuel station information that exists in the 
system in JSON format. 
4. The ULIP system will provide data in JSON Object format in the response body. 
 
Request: The request must be of the following format, where State Code, State Name  or 
geographical location (longitude, latitude, and radius) are passed within the URL post request 
body in JSON format.

1.4 Data Transmission & Authentication Mechanism 
All data exchanges will be securely done with HTTPS. ULIP's system will request data from JIOBP 
through a URL with the following format: 
For staging - https://www.ulipstaging.dpiit.gov.in/ulip/v1.0.0/JIOBP/01 
 
Body:

implemented by the ULIP system. The process is as follows:

password, the ULIP system will return a basic authorization token to you. You can use this 
token to communicate with the ULIP system until the token gets expired.
