ULIP Integration Document   
          
 
Doc Ref. No: ULIP Integration Doc Version No: 5.0 Page 6 of 70 
 
1.1 Purpose 
 
The purpose of this document is to define and provide details for accessing API for  
transaction details from IWAI (Inland Waterways Authority of India ) system from ULIP 
system. This document details the following points: 
 
1. Data Integration between IWAI and ULIP web service : Identification of operational 
points where data integration between IWAI and ULIP web service will be needed. 
 
2. Technical Approach for performing Data Integration  
 
The Overall Description 
Users will share information based on data sent by user ULIP system will call IWAI API 
for accessing information. 
Followings are the points for accessing cargo information: - 
 
1. This API will share data based on information provided by users. 
 
2. ULIP will expose API for getting data from IWAI API. 
 
3. IWAI/01 API will take information from user and get data from IWAI API. 
1.2 Data Integration between IWAI System and ULIP application 
 
Users will share information with the ULIP system based on data shared ULIP will 
provide data to user.

1.10.1 Technical Approach  
21. All the data will be shared through rest web services. 
22. ULIP system will provide  YEAR1, YEAR2, NWTYPE and TYPE for which detail is 
required. 
23. IWAI API will share details of cargo information which exist in IWAI system in JSON format. 
24. ULIP system will provide the data in JSON Object format in response body.

IWAI API.

1.18  Data Transmission & Authentication Mechanism 
 
All data exchange would be done over secure HTTP (HTTPS). Request from ULIP's system would 
be made in IWAI system through a data exchange URL that has following form: 
 
For Production: https://www.ulip.dpiit.gov.in/ulip/v1.0.0/IWAI/01 
 
Body:  
 
{ } 
 
Access to above data exchange URL would be authorized by use of a security mechanism 
implemented by the ULIP system. It is as follows: 
 
• First time access:  It would require a username and password [which would be shared with 
user beforehand].  Once user hit with valid user id and password, ULIP system will return a 
basic authorization token to  user, using that token user will communicate with ULIP system 
until tokens will not get expired. 
 
Brief summary of HTTP Basic Authentication is as follows: 
 
First time User hits ULIP secured API through username and password for access token as follow- 
 
curl --location --request POST 
'https://www.ulip.dpiit.gov.in/ulip/v1.0.0/user/login' \ 
--header 'Accept: application/json' \ 
--header 'Content-Type: application/json' \ 
--data-raw '{ 
"username": "xxxx", 
"password": "xxxx@123"}' 
 
Authorization:

minutes. If there is no request coming from user for 30 minutes, then session (token) will be 
expired, and user need to re authenticate.
