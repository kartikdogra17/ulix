Introduction 
1.1 Purpose 
 
The purpose of this document is to define and provide details for accessing API for Gati 
Shakti system information (information about nhno and stated available in Gati Shakti 
system) from ULIP system. This document details the following points: 
 
1. Data Integration between GATISHAKTI and ULIP web service : Identification of 
operational points where data integration between GATISHAKTI and ULIP web service 
will be needed. 
 
2. Technical Approach for performing Data Integration  
 
The Overall Description 
Users will share information such as NH number based on data sent by user ULIP 
system will call respective GATISHAKTI API for accessing information. 
 
Following are the points for accessing vehicle information: - 
 
1. This API will share data based on information provided by users. 
 
2. ULIP will expose API for getting data from GATISHAKTI API. 
 
3. GATISHAKTI/02 API will take NH number from user and get data from GATISHAKTI 
API. 
1.2 Data Integration between GATISHAKTI System and ULIP 
application 
 
Users will share information with the ULIP system based on data shared ULIP will 
provide data to user.

1.3.1 Technical Approach  
1. All the data will be shared through rest web services. 
2. ULIP system will provide NH number for which detail is required. 
3. GATISHAKTI API will share details of national highway road  information which exist in 
GATISHAKTI system in JSON format. 
4. GATISHAKTI Integration will add JSON in response key in response body. 
5. ULIP system will provide the data in JSON Object format in response body. 
 
Example: NH number NH-71 is shared by ULIP system, then GATISHAKTI-integration 
will make a request to GATISHAKTI API. 
 
Request: The request must be of the following format, where national highway (NH) number is 
passed within the URL body in JSON format. 
 
For Staging: https://www.ulipstaging.dpiit.gov.in/ulip/v1.0.0/GATISHAKTI/01
