Introduction 
1.1 Purpose 
 
The purpose of this document is to define and provide details for accessing API for  E-
Challan system information  (information about vehicle number  available in  E-Challan 
system) from ULIP system. 
This document details the following points: 
 
1. Data Integration between E-Challan and ULIP web service: Identification of operational 
points where data integration between E-Challan and ULIP web service will be needed. 
 
2. Technical Approach for performing Data Integration  
 
The Overall Description 
 
User will share the information such as vehicle number based on data send by user 
ULIP system will call respective E-Challan API for accessing information. 
 
Following are the point for accessing vehicle information: - 
 
1. This API will share data based on information provided by user. 
 
2. ULIP will expose API for getting data from E-Challan API. 
 
3. ECHALLAN/01 API will take vehicle number from user and get data from E-Challan 
API. 
1.2 Data Integration between E-Challan System and ULIP application 
 
User will share information to ULIP system based on data shared ULIP will provide data 
to user. 
 
1.3 ECHALLAN/01 
 
This API will take vehicle number and connect with E-Challan API to get data.

1.3.1 Technical Approach  
1. In this, on staging server we are fetching the data from 3 rd party E-Challan API directly 
without hitting any 3rd party AUTH API. 
2. In production server for get the data from 3 rd party E-Challan API, we have to first hit the 
3rd party AUTH API for get the token and then we use the token in the 3rd party E-Challan 
API, we are using the AUTH token API internally. 
3. All the data will be shared through rest web services. 
4. ULIP system will provide vehicle number for which detail is required. 
5. E-Challan API will share details of vehicle details which exist in E-Challan system in JSON 
format. 
6. ECHALLAN Integration will add JSON in response key in response body. 
7. ULIP system will provide the data in JSON Object format in response body. 
 
Example: 
 
Vehicle number KL150000 is shared by ULIP system, then ECHALLA-integration will 
make a request to E-Challan API.

1.4 Data Transmission & Authentication Mechanism 
 
All data exchange would be done over secure HTTP (HTTPS). Request from ULIP's system would 
be made in ECHALLAN system through a data exchange URL that has following form: 
 
For staging - 
https://www.ulipstaging.dpiit.gov.in/ulip/v1.0.0/ECHALLAN/01 
 
{ 
    "vehicleNumber": "KL150000" 
} 
 
Access to above data exchange URL would be authorized by use of a security mechanism 
implemented by the ULIP system. It is as follows: 
 
• First time access:  It would require a username and password [which would be shared with 
user beforehand].  Once user hit with valid user id and password, ULIP system will return a 
basic authorization token to  user, using that token user will communicate with ULIP system 
until token will not get expired.
