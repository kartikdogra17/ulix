Introduction 
1.1 Purpose 
 
 
The purpose of this document is to define and provide details for accessing API for  
MOPNG system information (information about petrol pumps and natural gas stations on the 
basis stcode or latitude, longitude and radius) from ULIP system 
 
 
 
This document details the following points: 
 
1. Data Integration between MOPNG and ULIP web service : Identification of operational 
points where data integration between MOPNG and ULIP web service will be needed. 
 
2. Technical Approach for performing Data Integration  
 
The Overall Description 
 
Users will need to share their stcode, or geolocation (latitude, longitude and radius) to 
access the list of public petrol pumps through the rest API. 
 
Here are some points to keep in mind when accessing MOPNG API data information: 
 
 The API will only share data that is based on the user's provided information. 
 ULIP will expose API for getting data from MOPNG API. 
 The MOPNG/01 API will take stcode, or geolocation (latitude, longitude and 
radius) from user and get data. 
 radius value should be less than or equal to 100. 
 
 
1.2 Data Integration between MOPNG System and ULIP application 
 
The ULIP system will receive information from the user and provide data in return. 
 
1.3 MOPNG/01

This API is designed to retrieve information about petrol pumps and natural gas stations. It can 
be used by providing either the take stcode, or geolocation (latitude, longitude and radius) of 
the desired location. 
 
Please note that when making a request, all of the JSON keys are mandatory in the payload. If 
you choose to use the stcode to access MOPNG API data, then latitude, longitude and radius 
fields should be left empty. 
 
{ 
    "stcode": "28", 
    "latitude": "", 
    "longitude": "", 
    "radius": "" 
} 
 
When sending geolocation(latitude, longitude and radius) data, if the user provides 
geocoordinate latitude, longitude and radius, then the stcode will be empty. 
 
{ 
    "stcode":"", 
    "latitude": "14.3473952000", 
    "longitude": "78.0001640500", 
    "radius":"1" 
}

1.3.2 MOPNG Api scheduler  
We have implemented a scheduler on the ULIP system that will call the MOPNG API and store 
the response in the mopng_data_dump database table. This scheduler is configured to execute the 
API call at midnight on the 1st day of every month. 
 
1.4 Data Transmission & Authentication Mechanism 
 
All data exchanges will be securely done over HTTPS. ULIP's system will request data from 
MOPNG through a URL with the following format: 
 
For Staging API -- 
https://www.ulipstaging.dpiit.gov.in/ulip/v1.0.0/MOPNG/01 
 
Body:  
{ 
    "stcode":"", 
    "latitude": "14.3473952000", 
    "longitude": "78.0001640500", 
    "radius":"1" 
}

To access the data exchange URL, you would need to use a security mechanism that is 
implemented by the ULIP system. The process is as follows: 
 
- First time access: you would require a username and password. The username and password 
would be shared with you beforehand. Once you enter the valid username and password, the 
ULIP system will return a basic authorization token to you. You can use this token to 
communicate with the ULIP system until the token gets expired. 
 
In brief, HTTP Basic Authentication works as follows: 
 
When you hit the ULIP secured API for the first time, you need to provide a username and 
password to get an access token.

    "password": "xxxx@123"
