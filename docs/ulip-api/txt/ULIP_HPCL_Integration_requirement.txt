Introduction 
1.1 Purpose 
 
The purpose of this document is to define and provide details for accessing API for  
HPCL system information (information about petroleum and natural gas stations based on State 
Code or geographical location (longitude, latitude, and radius) value from ULIP system. 
 
This document details the following points: 
 
1. Data Integration between HPCL and ULIP web service : Identification of operational 
points where data integration between HPCL and ULIP web service will be needed. 
 
2. Technical Approach for performing Data Integration  
 
The Overall Description 
 
Users will need to share their State Code or geographical location (longitude, latitude, and 
radius) to access the list of public petroleum and natural gas stations through the rest API. 
 
Here are some points to keep in mind when accessing HPCL API data information: 
 
• The API will only share data that is based on the user's provided information. 
• ULIP will expose API for getting data from HPCL API. 
• The HPCL/01 API will take user information’s from user for register that user. 
• The HPCL/02 API will take State Code or geographical location (longitude, latitude, and 
radius) to give information about petroleum and natural gas stations to the user. 
 
1.2 Data Integration between HPCL System and ULIP application 
 
The ULIP system will receive information from the user and provide data in return. 
1.3 HPCL/01 
 
This API is designed to register the user to the HPCL system based on user information. User will 
provide the user information and once user successfully registers, then they will get the reference 
number in the response.

1.4 HPCL/02 
 
This API is designed to retrieve information about petroleum and natural gas stations. It can be 
used by providing either the take state Code or the geographical location (longitude, latitude, 
and radius) of the desired location. 
 
HPCL merchant(outlet) details are updated weekly, and retail selling prices (RSP) 
are updated daily to ensure users always see the latest and accurate information. 
 
Please note that when making a request, all of the JSON keys are mandatory in the payload . 
First, the user must enter the reference number. If this reference number exists on the HPCL side, 
the user can then enter either the state Code or geographical location (longitude, latitude, and 
radius). The reference number can be obtained when they hit the HPCL/01 API. 
  
If you choose to use the state Code to access HPCL API data, then geographical location 
(longitude, latitude, and radius) fields should be left empty.

1.5 Data Transmission & Authentication Mechanism 
 
All data exchanges will be securely done over HTTPS. ULIP's system will request data from HPCL 
through a URL with the following format: 
 
For staging - 
 
https://www.ulipstaging.dpiit.gov.in/ulip/v1.0.0/HPCL/01 
 
Body:  
{ 
    "customerName": "test", 
    "address": "test address", 
    "district": "Gautam Bhuda Nagar", 
    "state": "Uttar Pradesh", 
    "email": "test@paytm.com", 
    "monthlyFuelConsumption": "10000", 
    "userId": "test", 
    "userIP": "193.2.2.2", 
    "mobileNo": "7879877897" 
} 
 
To access the data exchange URL, you would need to use a security mechanism that is 
implemented by the ULIP system. The process is as follows: 
 
- First time access: you would require a username and password. The username and password 
would be shared with you beforehand. Once you enter the valid username and password, the 
ULIP system will return a basic authorization token to you. You can use this token to 
communicate with the ULIP system until the token gets expired.
