Introduction 
1.1 Purpose 
 
The purpose of this document is to define and provide details for accessing API for PESO 
system information from ULIP system. 
This document details the following points: 
 
1. Data Integration between PESO and ULIP web service : Identification of operational 
points where data integration between PESO and ULIP web service will be needed. 
 
2. Technical Approach for performing Data Integration  
 
The Overall Description 
Users will share information such as Vehicle Registration Number 
based on data sent by user ULIP system will call respective PESO API for accessing 
information. 
 
Following is the point for accessing vehicle information: - 
 
1. This API will share data based on information provided by users. 
 
2. ULIP will expose API for getting data from PESO API. 
 
3. PESO/01 API will take Vehicle Registration Number from user and get data from PESO 
API. 
1.2 Data Integration between PESO System and ULIP application 
 
Users will share information with the ULIP system based on data shared ULIP will 
provide data to user.

1.3.1 Technical Approach  
1. All the data will be shared through rest web services. 
2. ULIP system will provide Vehicle Registration Number for which detail is required. 
3. PESO API will share details  of CNG certificate details of vehicles  based on  Vehicle 
Registration Number which exist in PESO system in JSON format. 
4. PESO Integration will add JSON in response key in response body. 
5. ULIP system will provide the data in JSON Object format in response body. 
 
Example: Vehicle Registration Number is shared by ULIP system, then PESO-integration 
will make a request to PESO API. 
 
Request: The request must be of the following format, where Vehicle Registration Number is 
passed within the URL body in JSON format. 
 
For Staging: https://www.ulipstaging.dpiit.gov.in/ulip/v1.0.0/PESO/01 
 
{ " VehicleRegistrationNumber": " HR38AC7120"}

1.4 Data Transmission & Authentication Mechanism 
 
All data exchange would be done over secure HTTP (HTTPS). Request from ULIP's system would 
be made in PESO system through a data exchange URL that has following form: 
 
For Staging: https://www.ulipstaging.dpiit.gov.in/ulip/v1.0.0/PESO/01 
 
{" VehicleRegistrationNumber": " HR38AC7120"} 
 
Access to above data exchange URL would be authorized by use of a security mechanism 
implemented by the ULIP system. It is as follows: 
 
• First time access:  It would require a username and password [which would be shared with 
user beforehand].  Once user hit with valid user id and password, ULIP system will return a 
basic authorization token to  user, using that token user will communicate with ULIP system 
until tokens will not get expired. 
 
Summary of HTTP Basic Authentication is as follows:
