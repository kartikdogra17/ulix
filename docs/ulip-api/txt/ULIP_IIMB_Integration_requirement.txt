Introduction 
1.1 Purpose 
 
The purpose of this document is to define and provide details for accessing API for  
calculating Carbon Emission factor for different mode of transportation from ULIP system. 
This document details the following points: 
 
1. Data Integration between Other System  and ULIP web service : Identification of 
operational points where data integration between other system and ULIP web service will 
be needed. 
 
2. Technical Approach for performing Data Integration  
 
 
1.2 Data Integration between other system and ULIP application 
 
User will share information to ULIP system based on data shared ULIP will provide data 
(carbon emission factor) to the user. 
1.3 CARBON/01 
 
This API will take Weight, Distance and Trip Count and based on the emission factor 
and user input data, ULIP System will calculate the total carbon emitted and send back 
the response to the user.

1.3.1 Technical Approach  
1. All the data will be shared through rest web services. 
2. ULIP system will provide data (carbon emitted ) for which data is shared. 
3. ULIP system will provide the data in JSON Object format in response body. 
 
 
Example: 
 
Let Distance 182.3 Km, Weight 218.6 tonne and tripCount is 1 this is the data shared by the 
user, then Ulip system will calculate the total carbon emitted in kg co2 based on the data shared 
by the user. 
 
Calculation Example: (distance * weight * tripCount * WTT Emission factor) + (distance * 
weight * tripCount * TTW Emission factor)

    "message": "Success" 
} 
 
 
 
Status Code 200: corporate data response 
Status Code 400: Bad request (Invalid json syntax, invalid json key) 
Status Code 401 or 403: Unauthenticated or Unauthorized 
Status Code 500: Some internal server error occurred 
Status Code 502: Server is not responding. 
 
1.7 Data Transmission & Authentication Mechanism 
 
All data exchange would be done over secure HTTP (HTTPS). Request from ULIP's system would 
be made in IWAI system through a data exchange URL that has following form: 
 
For Production 
 
https://www.ulip.dpiit.gov.in/ulip/v1.0.0/CARBON/01 
 
 
Body:  
 
{ 
    "distance": "18233.7", 
    "weight": "0.0", 
    "tripCount": "1" 
} 
 
Access to above data exchange URL would be authorized by use of a security mechanism 
implemented by the ULIP system. It is as follows: 
 
• First time access:  It would require a username and password [which would be shared with 
user beforehand].  Once user hit with valid user id and password, ULIP system will return a 
basic authorization token to  user, using that token user will communicate with ULIP system 
until token will not get expired.
