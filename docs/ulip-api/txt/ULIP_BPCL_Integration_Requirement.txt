Introduction 
1.1 Purpose 
 
 
The purpose of this document is to define and provide details for accessing API for 
BPCL system information (information about oil and natural gas stations based on 
StateCode or geographical location (longitude, latitude, and radius) value from ULIP 
system 
 
This document details the following points: 
 
1. Data Integration between BPCL and ULIP web service: Identification of operational 
points where data integration between BPCL and ULIP web service will be needed. 
 
2. Technical Approach for performing Data Integration 
 
The Overall Description 
 
Users will need to share their State Code or geographical location (longitude, latitude, 
and radius) to access the list of public petroleum and natural gas stations through the rest 
API. 
 
Here are some points to keep in mind when accessing BPCL API data information: 
 
• The API will only share data that is based on the user's provided information. 
• ULIP will expose an API for getting data from the BPCL API. 
• The BPCL/01 API will take the user information from the user to register that user. 
And the user will receive ReferenceNo in response, from this ReferenceNo user will 
be able to access the BPCL/02 API. 
• The BPCL/02 API will take ReferenceNo and State Code or geographical location 
(longitude, latitude, and radius) to give information about petroleum and natural gas 
stations to the user. 
 
1.2 Data Integration between BPCL System and ULIP application 
The ULIP system will receive information from the user and provide data in return. 
1.3 BPCL/01 
This API is designed to register the user to the BPCL system based on user information. The user 
will provide their information, and once the user successfully registers, they will get the reference 
number in the response.

1.4 BPCL/02 
This API is designed to retrieve information about petroleum and natural gas stations. It can be 
used by providing either the take State Code or the geographical location (longitude, 
latitude, and radius) of the desired location. 
BPCL merchant(outlet) details are updated weekly, and retail selling prices (RSP) are 
updated daily to ensure users always see the latest and accurate information. 
Please note that when making a request, all of the JSON keys are mandatory in the payload . 
First, the user must enter the reference number. If this reference number exists on the BPCL side, 
the user can then enter either the State Code or the geographical location (longitude, latitude, 
and radius). The reference number can be obtained when they hit the BPCL/01 API. 
 
If you choose to use the State Code to access BPCL API data, then the geographical 
location (longitude, latitude, and radius) fields should be left empty. 
 
Use the state code from the table below to inquire about the BPCL outlet in the 
respective state.
