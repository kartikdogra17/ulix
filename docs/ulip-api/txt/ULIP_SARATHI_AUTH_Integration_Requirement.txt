Introduction 
1.1 Purpose 
 
The purpose of this document is to define and provide details for authenticating Sarathi Response 
data with respect to driving license number and dob which we have received from sarathi system. 
This document details the following points: 
 
1. Data Integration and verification between SARATHI and ULIP web service : 
Identification of operational points where data integration and verification between 
SARATHI and ULIP web service will be needed. 
 
2. Technical Approach for performing Data Integration  
 
The Overall Description 
 
User will share the information such as driving license number and date of birth and will at 
least share either driver name or permit    based on data send by user ULIP system will call 
respective SARATHI API for accessing information and then verify data based on user input. 
 
Following are the point for accessing vehicle information: - 
 
1. This API will share driving license data based on information provided by user. 
 
2. ULIP will expose API for getting data from SARATHI API and then verify the response if 
correct information is there or not in the response which we are getting from SARATHI 
API. 
 
3. SARATHI/verifySarathiData  API will take driving license and date of birth and will 
share at least driver name and permit from user and get data from SARATHI API and 
then will verify if correct driver name (which is bioFullName field in SARATHI API 
response) and permit (which is covabbrv field in SARATHI API response) is coming 
from SARATHI API response or not. 
 
1.2 Data Integration between SARATHI System and ULIP application 
 
User will share information to ULIP system based on data shared ULIP will verify the data for 
the user. 
1.3 SARATHI/verifySarathiData 
 
This API will take driving license number and connect with SARATHI API to get data.

1.3.1 Technical Approach  
1. All the data will be shared through rest web services. 
2. ULIP system will provide driving license number and date of birth and will at least 
share either driver name or permit for which detail and verification needs to be done. 
3. SARATHI API will share details of driving license information which exist in SARATHI 
system in JSON format. 
4. ULIP system will verify the response which is received from SARATHI API based on the 
driver name and permit which is provided by the user. 
 
5. ULIP system will provide the data in JSON Object format in response body. 
 
Example: 
 
Driving license Number MP44 20100005566 , date of birth 1987-06-02, driver name Vikas 
Tailor and Permit LMV  is shared by ULIP system, then SARATHI-integration will make a 
request to SARATHI API.

passed within the URL body in JSON format.

1.4 Data Transmission & Authentication Mechanism 
 
All data exchange would be done over secure HTTP (HTTPS). Request from ULIP's system would 
be made in SARATHI system through a data exchange URL that has following form: 
 
For staging – 
 
https://www.ulipstaging.dpiit.gov.in/ulip/v1.0.0/AUTHAPI/03 
 
Body:  
 
{ 
    "dlnumber": "GJ04 20120005008", 
    "dob": "1987-05-26", 
    "driverName":"VIKAS TAILOR", 
  
} 
 
Access to above data exchange URL would be authorized by use of a security mechanism 
implemented by the ULIP system. It is as follows: 
 
 First time access: It would require a username and password [which would be shared with 
user beforehand].  Once user hit with valid user id and password, ULIP system will return a 
basic authorization token to user, using that token user will communicate with ULIP system 
until token will not get expired. 
 
Brief summary of HTTP Basic Authentication is as follows: 
 
First time when User will hit ULIP secured API through username and password for access token 
as follow-

    "password": "xx"
