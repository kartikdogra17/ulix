Introduction 
1.1 Purpose 
 
The purpose of this document is to define and provide details for accessing API for  
transaction details from MCA (Ministry of Corporate Affairs) system from ULIP system. 
This document details the following points: 
 
1. Data Integration between MCA and ULIP web service : Identification of operational 
points where data integration between MCA and ULIP web service will be needed. 
 
2. Technical Approach for performing Data Integration  
 
The Overall Description 
Users will share information such as Corporate Identification Number (CIN) based on 
data sent by user ULIP system will call MCA API for accessing information. 
 
Following is the point for accessing cargo information: - 
 
1. This API will share data based on information provided by users. 
 
2. ULIP will expose API for getting data from IWAI API. 
 
3. MCA/01 API will take Corporate Identification Number (CIN) from user and get data 
from MCA API. 
1.2 Data Integration between MCA System and ULIP application 
 
Users will share information with the ULIP system based on data shared ULIP will 
provide data to user.

1.8 Data Transmission & Authentication Mechanism 
 
All data exchange would be done over secure HTTP (HTTPS). Request from ULIP's system would 
be made in IWAI system through a data exchange URL that has following form: 
 
For Production: https://www.ulip.dpiit.gov.in/ulip/v1.0.0/MCA/01 
 
Body:  
{"cin":"L17110MH1973PLC019786"} 
 
Access to above data exchange URL would be authorized by use of a security mechanism 
implemented by the ULIP system. It is as follows: 
 
• First time access:  It would require a username and password [which would be shared with 
user beforehand].  Once user hit with valid user id and password, ULIP system will return a 
basic authorization token to  user, using that token user will communicate with ULIP system 
until tokens will not get expired. 
 
Summary of HTTP Basic Authentication is as follows: 
 
First time when User hits ULIP secured API through username and password for access token 
as follow- 
 
curl --location --request POST 'https://www.ulip.dpiit.gov.in/ulip/v1.0.0/user/login' \ 
--header 'Accept: application/json' \ 
--header 'Content-Type: application/json' \ 
--data-raw '{ 
"username": "xxxx", 
"password": "xxxx@123"}' 
 
Authorization:   
Bearer  
eyJhbGciOiJIUzUxMiJ9.eyJzdWIiOiJ0ZXN0MSIsImlhdCI6MTYyNTIzMDQyNywiYXBwcyI6I
mRhdGFwdXNoIn0.rhumwWJ8BWeeHe9CYmIV1UKyJk-kLHA_ovX5Zi2OwxEv-td-
KpxnfbKDI_8FZsOoggqx3Al-Du1y2qMoUD7uzA' 
 
Upon successful authentication, the user would be logged into the ULIP system and get an access
