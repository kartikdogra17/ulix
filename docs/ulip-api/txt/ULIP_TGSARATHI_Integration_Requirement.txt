Introduction 
1.1 Purpose 
 
This document defines and provides details for accessing the  API for TGSARATHI 
system information from the ULIP system. 
This document details the following points: 
 
1. Data Integration between TGSARATHI and ULIP web service : Identification of 
operational points where data integration between the Telangana Transport Department 
and ULIP web service will be needed. 
2. Technical Approach for Performing Data Integration  
The Overall Description 
The user will share information such as a Driving License (DL) based on data sent by the 
user. The ULIP system will call the respective TGSARATHI API to access information. 
 
The following are the points for accessing cargo information: - 
 
1. This API will share data based on information provided by the user. 
 
2. ULIP will expose API for getting data from TGSARATHI API. 
 
3. TGSARATHI/01 API will take a Driving License (DL) from the user and get data from 
TGSARATHI/01 API. 
1.2 Data Integration between TGSARATHI System and ULIP 
application 
 
The user will share information with the ULIP system based on the data shared ULIP 
will provide data to the user. 
1.3 TGSARATHI/01 
 
This API will take the driver's license number and connect with the TGSARATHI API to 
get data.

1.3.1 Technical Approach  
1. All the data will be shared through the rest web services. 
2. The ULIP system will provide the driver's license number, which is required for details. 
3. TGSARATHI API will share details of driver's license information that exists in the 
TGSARATHI system in JSON format. 
4. TGSARATHI Integration will add JSON in the response key in the response body. 
5. The ULIP system will provide the data in JSON Object format in the response body. 
 
Example: 
 
The ULIP system shares the driver's license number, and TGSARATHI-integration will 
request TGSARATHI API.

the URL body in JSON format.

1.4 Data Transmission & Authentication Mechanism 
 
All data exchange would be done over secure HTTP (HTTPS). Request from ULIP's system would 
be made in the TGSARATHI system through a data exchange URL that has the following form:

Body:  
{"dlnumber": "AP01120130018301"} 
 
Access to above data exchange URL would be authorized by use of a security mechanism 
implemented by the ULIP system. It is as follows: 
• To access the system for the first time, you will need a username and password, which will 
be provided in advance. Once you enter your valid user ID and password, the ULIP system 
will return a basic authorisation token. You can use this token to communicate with the ULIP 
system until it expires.
