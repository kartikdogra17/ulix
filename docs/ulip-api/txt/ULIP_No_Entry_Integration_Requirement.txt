Introduction 
1.1 Purpose 
 
The purpose of this document is to define and provide details for getting no entry data 
based on state code from ULIP system. 
This document details the following points: 
 
1. Data Integration between Other System  and ULIP web service : Identification of 
operational points where data integration between other system and ULIP web service will 
be needed. 
 
2. Technical Approach for performing Data Integration  
 
1.2 Data Integration between other system and ULIP application 
 
Users will share information to ULIP system based on data shared ULIP will provide 
data (toll plaza rate) to the user. 
 
1.3 NOENTRY/01 
 
This API will take stateCode and based on the user input data, ULIP System will find 
the no entry data for the state code and send back the response to the user. 
 
 
S. No. Field Name Field Description Format Required/Not – 
Required 
Length 
1  stateCode  State code for the 
particular state ^\d{1,5}$ Required  Max 5 
digit 
 
 
1.3.1 Technical Approach  
1. All the data will be shared through rest web services. 
2. ULIP system will provide data (toll rate) for which data is shared. 
3. ULIP system will provide the data in JSON Object format in response body. 
 
Request: The request must be of the following format, where stateCode is passed within the 
request body in JSON format.

1.4 Data Transmission & Authentication Mechanism 
 
All data exchange would be done over secure HTTP (HTTPS). Request from ULIP's system would 
be made in IWAI system through a data exchange URL that has following form: 
 
For Production: https://www.ulip.dpiit.gov.in/ulip/v1.0.0/NOENTRY/01 
 
Body: 
  
{"stateCode":"13”} 
 
Access to above data exchange URL would be authorized by use of a security mechanism 
implemented by the ULIP system. It is as follows: 
 
• First time access:  It would require a username and password [which would be shared with 
user beforehand].  Once user hit with valid user id and password, ULIP system will return a 
basic authorization token to  user, using that token user will communicate with ULIP system 
until token will not get expired. 
 
Summary of HTTP Basic Authentication is as follows: 
 
First time when User will hit ULIP secured API through username and password for access token 
as follow- 
 
curl --location --request POST 'https://www.ulip.dpiit.gov.in/ulip/v1.0.0/user/login' \ 
--header 'Accept: application/json' \ 
--header 'Content-Type: application/json' \ 
--data-raw '{ 
"username": "xxxx", 
"password": "xxxx@123"}'
