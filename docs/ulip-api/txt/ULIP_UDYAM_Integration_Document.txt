Introduction 
1.1 Purpose 
 
The purpose of this document is to define and provide details for accessing API for 
UDYAM system information from ULIP system. 
This document details the following points: 
 
1. Data Integration between UDYAM and ULIP web service: Identification of operational 
points where data integration between UDYAM and ULIP web service will be needed. 
 
2. Technical Approach for performing Data Integration  
 
The Overall Description 
 
Users will share information such as UdyamNo, based on data sent by user ULIP 
system will call respective UDYAM API for accessing information. 
 
Following are the points for accessing different udyam information: - 
 
1. This API will share data based on information provided by users. 
 
2. ULIP will expose API for getting data from UDYAM API. 
 
3. UDYAM/01 API will take UdyamNo from user and get data from UDYAM API. 
 
1.2 Data Integration between UDYAM System and ULIP application 
 
Users will share information with the ULIP system based on data shared ULIP will 
provide data to user. 
1.3 UDYAM/01 
 
This API will take UdyamNo and connect with UDYAM API to get data.

1.3.1 Technical Approach  
1. All the data will be shared through rest web services. 
2. ULIP system will provide UdyamNo for which detail is required. 
3. UDYAM API will share details different udyam numbers which exist in UDYAM system in 
JSON format. 
4. UDYAM Integration will add JSON in response key in response body. 
5. ULIP system will provide the data in JSON Object format in response body. 
 
Example: " UdyamNo " "UDYAM-AP-01-0019566" is shared by ULIP system, then 
UDYAM-integration will make a request to UDYAM API. 
 
Request: 
 
The request must be of the following format, where UdyamNo is passed within the URL body in 
JSON format. 
 
https://www.ulip.dpiit.gov.in/ulip/v1.0.0/UDYAM/01 
 
{" UdyamNo ": "UDYAM-AP-01-0019566"} 
 
Curl URL 
 
curl --location 'https://www.ulip.dpiit.gov.in/ulip/v1.0.0/UDYAM/01' \

1.4 Data Transmission & Authentication Mechanism 
 
All data exchange would be done over secure HTTP (HTTPS). Request from ULIP's system would 
be made in UDYAM system through a data exchange URL that has following form: 
 
https://www.ulip.dpiit.gov.in/ulip/v1.0.0/UDYAM/01 
 
Body:  
{" UdyamNo": " UDYAM-AP-01-0019566"} 
 
Access to above data exchange URL would be authorized by use of a security mechanism 
implemented by the ULIP system. It is as follows: 
 
• First time access:  It would require a username and password [which would be shared with 
user beforehand].  Once user hit with valid user id and password, ULIP system will return a 
basic authorization token to  user, using that token user will communicate with ULIP system 
until tokens will not get expired. 
 
Summary of HTTP Basic Authentication is as follows: 
 
First time User hits ULIP secured API through username and password for access token as follow-

‘https://www.ulip.dpiit.gov.in/ulip/v1.0.0/user/login’
