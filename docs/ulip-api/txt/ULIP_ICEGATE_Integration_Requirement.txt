Introduction 
1.1 Purpose 
 
The purpose of this document is to define and provide details for accessing API for the 
ICEGATE (Indian Customs Electronic Data Interchange (EDI) Gateway) system 
information (e-filing services) from the ULIP system. 
 
This document details the following points: 
 
1. Data Integration between ICEGATE and ULIP web service: Identification of 
operational points where data integration between ICEGATE and ULIP web service will 
be needed. 
 
2. Technical Approach for Performing Data Integration  
 
The Overall Description 
 
User will share the information such as EGM number, BE number and shipping bill 
number based on data send by user ULIP system will call respective ICEGATE API for 
accessing information. 
 
Following are the point for accessing vehicle information: - 
 
This API will share data based on information provided by user. ULIP will expose API for getting 
data from ICEGATE API. 
 
1. ICEGATE/01  API will take IGM and IGM date number from user and get data from 
ICEGATE API. 
 
2. ICEGATE/02  API will take BE number and date from user and get data from ICEGATE 
API. 
 
3. ICEGATE/03  API will take BE number and date from user and get data from ICEGATE 
API. 
 
4. ICEGATE/04  API will take Site id, IMO code, Vessel code, arrival data from user and 
get data from ICEGATE API. 
 
5. ICEGATE/05  API will take shipping bill number & date from user and get data from 
ICEGATE API. 
 
ULIP Integration Requirement Document 
  
          
 
Doc Ref. No: ULIP Integration Doc Version No: 4.0 Page 5 of 66 
 
6. ICEGATE/06  API will take shipping bill number & date from user and get data from 
ICEGATE API. 
 
 
7. ICEGATE/07  API will take the IGM number and IGM date from the user and get data 
from the ICEGATE API. 
8. ICEGATE/08  API will take the EGM number and EGM date from the user and get data 
from the ICEGATE API. 
9. ICEGATE/09 will provide MAWB details when Location and MAWB details are entered 
as input  
10. ICEGATE/10 will provide MAWB details when the Master Bill Number and House 
Airway Bill no are entered as input 
11. ICEGATE/11 will provide Air Export General Manifest & Air Import General Manifest Job 
Status Details 
12. ICEGATE/12 will provide Manual/Courier/Postal SB details 
13. ICEGATE/13 will provide e-Seal details 
 
1.2 Data Integration between the ICEGATE System and the ULIP 
application 
 
The user will share information with the ULIP system based on data shared ULIP will 
provide data to the user.

1.3.1 Technical Approach

1.16  Data Transmission & Authentication Mechanism 
 
All data exchange would be done over secure HTTP (HTTPS). Request from ULIP's system 
would be made in the ICEGATE system through a data exchange URL that has the following 
form: 
 
For Production: 
 
https://www.ulip.dpiit.gov.in/ulip/v1.0.0/ICEGATE/01 
 
Body:  
 
{"igmNo":"1234","igmDt":"25102021"} 
 
 
Access to the data exchange URL will be authorised through a security mechanism 
implemented by the ULIP system. The process is as follows: 
 
- First-Time Access: Users will need a username and password, which will be provided in 
advance. Once the user enters a valid username and password, the ULIP system will return a 
basic authorisation token. This token will allow the user to communicate with the ULIP system 
until it expires. 
 
Here is a summary of HTTP Basic Authentication: 
 
During the initial access, the user will submit their username and password to the ULIP secured 
API to obtain an access token.
