Introduction 
1.1 Purpose 
 
The purpose of this document is to define and provide details for accessing API for  
EV charging stations across India, via using input parameters such as state  and 
geolocation such as latitude and longitude.  
 
This document details the following points: 
 
1. Data Integration between Bureau of Energy Efficiency (BEE) and ULIP web service: 
Identification of operational points where data integration between  Bureau of Energy 
Efficiency (BEE) and ULIP web service will be needed. 
 
2. Technical Approach for Performing Data Integration  
 
The Overall Description 
Users will need to share their state ID or geolocation to access the list of public electric 
vehicle charging stations through the rest API. A comprehensive list of state ID can be 
found by clicking on the provided link. 
 
Here are some points to keep in mind when accessing EV charging station information: 
 
• The API will only share data that is based on the user's provided information. 
 
• ULIP will provide an API that allows users to obtain data from the BEE API. 
 
• The EVYATRA/01 API will retrieve data from the BEE database using the stateId, 
or geolocation (latitude and longitude) provided by the user. 
 
1.2 Data Integration between EVYATRA System and ULIP application 
 
The ULIP system will receive information from the user and provide data in return. 
 
1.3 EVYATRA/01 
 
This API is designed to retrieve information about electric vehicle (EV) charging stations. It can 
be used by providing either the state ID or the geolocation (latitude and longitude) of the desired 
location.

1.3.1 Technical Approach  
 
1. All the data will be shared through REST web services. 
2. The user will share the input for which information is required. 
3. EVYATRA API will share details of EV charging station information that exists in the BEE 
system in JSON format. 
4. The ULIP system will provide data in JSON Object format in the response body. 
 
Example: 
 
Request: The request must be of the following format, where state ID, latitude and longitude 
are passed within the URL post request body in JSON format.

1.4 Data Transmission & Authentication Mechanism 
 
All data exchanges will be securely done over HTTPS. ULIP's system will request data from 
EVYATRA through a URL with the following format: 
 
For staging - 
https://www.ulipstaging.dpiit.gov.in/ulip/v1.0.0/EVYATRA/01 
 
Body:  
{ 
"stateId": "", 
    "lat": "18.503194", 
    "long": "73.969694" 
}

To access the data exchange URL, you would need to use a security mechanism that is 
implemented by the ULIP system. The process is as follows: 
 
- First time access: you would require a username and password. The username and password 
would be shared with you beforehand. Once you enter the valid username and password, the 
ULIP system will return a basic authorization token to you. You can use this token to 
communicate with the ULIP system until the token gets expired. 
 
In brief, HTTP Basic Authentication works as follows: 
 
When you hit the ULIP secured API for the first time, you need to provide a username and 
password to get an access token.
