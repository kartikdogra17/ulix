Introduction 
1.1 Purpose 
 
The purpose of this document is to define and provide details for accessing API for  
IOCL system information  (information about Indian oil  and natural gas stations  based on  
stateCode or geographical location (longitude, latitude, and radius) value from ULIP system 
 
This document details the following points: 
 
1. Data Integration between IOCL and ULIP web service : Identification of operational 
points where data integration between IOCL and ULIP web service will be needed. 
 
2. Technical Approach for performing Data Integration  
 
The Overall Description 
 
Users will need to share their stateCode or geographical location (longitude, latitude, and 
radius) to access the list of public petroleum and natural gas stations through the rest API. 
 
Here are some points to keep in mind when accessing IOCL API data information: 
 
• The API will only share data that is based on the user's provided information. 
• ULIP will expose API for getting data from IOCL API. 
• The IOCL/01 API will take user information’s from user for register that user. And user 
will receive ReferenceNo in response, from this ReferenceNo user will be able to access 
the IOCL/02 API. 
• The IOCL/02 API will take ReferenceNo and stateCode or geographical location 
(longitude, latitude, and radius) to give the information about petroleum and natural gas 
stations to the user. 
 
1.2 Data Integration between IOCL System and ULIP application 
 
The ULIP system will receive information from the user and provide data in return. 
1.3 IOCL/01 
 
This API is designed to register the user to the IOCL system based on user information. User will 
provide the user information and once user successfully register, then they will get the reference 
number in the response.

1.5 Data Transmission & Authentication Mechanism 
 
All data exchanges will be securely done with HTTPS. ULIP's system will request data from IOCL 
through a URL with the following format: 
 
For staging - 
 
https://www.ulipstaging.dpiit.gov.in/ulip/v1.0.0/IOCL/01 
 
Body:  
{ 
    "customerName": "test", 
    "address": "test address", 
    "district": "Gautam Bhuda Nagar", 
    "state": "Uttar Pradesh", 
    "email": "test@paytm.com", 
    "monthlyFuelConsumption": "10000", 
    "userId": "test", 
    "userIP": "193.2.2.2", 
    "mobileNo": "7879877897" 
} 
 
To access the data exchange URL, you would need to use a security mechanism that is 
implemented by the ULIP system. The process is as follows: 
 
- First time access: you will require a username and password. The username and password 
would be shared with you beforehand. Once you enter the valid username and password, the 
ULIP system will return a basic authorization token to you. You can use this token to 
communicate with the ULIP system until the token gets expired.

password to get an access token.
