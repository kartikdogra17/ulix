Introduction 
1.1 Purpose 
 
The purpose of this document is to define and provide details for accessing API for 
WAREHOUSE system information from ULIP system. 
 
This document details the following points: 
 
1. Data Integration between WAREHOUSE and ULIP web service : Identification 
of operational points where data integration between WAREHOUSE and ULIP web 
service will be needed. 
 
2. Technical Approach for performing Data Integration  
 
The Overall Description 
 
Users will share information such as StateCode, based on data sent by user ULIP 
system will call respective WAREHOUSE API for accessing information. 
 
Following are the points for accessing different warehouse locations: - 
 
1. This API will share data based on information provided by users. 
 
2. ULIP will expose API for getting data from WAREHOUSE API. 
 
3. WAREHOUSE/01 API will take StateCode from user and get data from 
WAREHOUSE API. 
 
1.2 Data Integration between WAREHOUSE System and ULIP 
application 
 
User will share information to ULIP system based on data shared ULIP will provide data 
to user. 
 
1.3 WAREHOUSE/01 
 
This API will take StateCode and connect with WAREHOUSE API to get data.

1.3.1 Technical Approach  
1. All the data will be shared through rest web services. 
2. ULIP system will provide StateCode for which detail is required. 
3. WAREHOUSE API will share details of locations of different warehouses which exist in 
WAREHOUSE system in JSON format. 
4. WAREHOUSE Integration will add JSON in response key in response body. 
5. ULIP system will provide the data in JSON Object format in response body. 
 
Example: "StateCode" "09" is shared by ULIP system, then WAREHOUSE-integration 
will make a request to WAREHOUSE API. 
 
Request: 
 
The request must be of the following format, where StateCode is passed within the URL body in 
JSON format. 
 
https://www.ulip.dpiit.gov.in/ulip/v1.0.0/WAREHOUSE/01 
 
{"StateCode": "09"}

1.4 Data Transmission & Authentication Mechanism 
 
All data exchange would be done over secure HTTP (HTTPS). Requests from ULIP's system 
would be made in WAREHOUSE system through a data exchange URL that has following form: 
 
https://www.ulip.dpiit.gov.in/ulip/v1.0.0/WAREHOUSE/01 
 
Body:  
 
{"StateCode": "09"} 
 
Access to above data exchange URL would be authorized by use of a security mechanism 
implemented by the ULIP system. It is as follows: 
 
• First time access:  It would require a username and password [which would be shared with 
user beforehand].  Once user hit with valid user id and password, ULIP system will return a 
basic authorization token to  user, using that token user will communicate with ULIP system 
until token will not get expired. 
 
Brief summary of HTTP Basic Authentication is as follows: 
 
First time when User will hit ULIP secured API through username and password for access token 
as follows-
