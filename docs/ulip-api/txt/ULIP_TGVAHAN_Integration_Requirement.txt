Introduction 
1.1 Purpose 
 
The purpose of this document is to define and provide details for accessing API for 
TGVAHAN system information from the ULIP system. 
This document details the following points: 
 
1. Data Integration between TGVAHAN and ULIP web service : Identification of 
operational points where data integration between the Telangana Transport Department 
and ULIP web service will be needed. 
 
2. Technical Approach for Performing Data Integration  
 
The Overall Description 
The user will share information such as vehicle numbers based on data sent by the 
user. The ULIP system will call the respective TGVAHAN API to access information. 
 
The following are the points for accessing cargo information: - 
 
1. This API will share data based on information provided by the user. 
 
2. ULIP will expose API for getting data from TGVAHAN API. 
 
3. TGVAHAN /01 API will take the vehicle number from the user and get data from 
TGVAHAN API. 
1.2 Data Integration between TGVAHAN System and ULIP application 
 
The user will share information with the ULIP system based on the data shared ULIP 
will provide data to the user. 
1.3 TGVAHAN/01 
 
This API will take the vehicle number and connect with the TGVAHAN API to get data.

1.3.1 Technical Approach  
1. All the data will be shared through the rest web services. 
2. The ULIP system will provide the Vehicle number for which detail is required. 
3. TGVAHAN API will share details of the vehicle registration information that exists in the 
TGVAHAN system in JSON format. 
4. TGVAHAN Integration will add JSON in the response key in the response body. 
5. The ULIP system will provide the data in JSON Object format in the response body. 
 
Example: 
 
Vehicle number TG08T1024 is shared by the ULIP system, and then TGVAHAN-
integration will request TGVAHAN API.

1.4 Data Transmission & Authentication Mechanism 
 
All data exchange would be done over secure HTTP (HTTPS). Request from ULIP's system would 
be made in the TGVAHAN system through a data exchange URL that has the following form: 
 
For Staging – 
 
https://www.ulipstaging.dpiit.gov.in/ulip/v1.0.0/TGVAHAN/01

Access to above data exchange URL would be authorized by use of a security mechanism 
implemented by the ULIP system. It is as follows: 
 
• First time access:  It would require a username and password [which would be shared with 
user beforehand].  Once user hit with valid user id and password, ULIP system will return a 
basic authorization token to  user, using that token user will communicate with ULIP system 
until token will not get expired.
